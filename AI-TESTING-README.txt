MANUAL CHATGPT TESTING

Open AI-testing.html. For each numbered photo, open a fresh ChatGPT conversation, upload only that photo from AI-test-photos, and paste the corresponding prompt. Use the same displayed model for all tests. Do not upload game.js, source credits, the whole game, or an answer key.

Record the first answer exactly, including incorrect answers. Do not retry until correct. If the model refuses or gives no usable option, record that separately and resolve it before importing; do not invent an option.

The entry page saves drafts in this browser when storage is available. Use Download draft as a backup and Import draft to resume elsewhere. When all 13 are filled, download the game results file. In the game choose Host settings > Import recorded AI answers. This enables recorded mode on that browser. To activate on another laptop, import the same results file there.

The photo copies are byte-identical to the game images and use neutral filenames. Prompts use the exact game questions and options in shuffled order. Results are host-entered, not independently authenticated. Online ChatGPT testing requires internet; the resulting game remains offline.

No genuine results have been filled by the builder. Difficulty is provisional. Keep correct and incorrect AI answers alike.
