BEAT THE AI — OFFLINE PRACTICE BUILD

Open index.html in Microsoft Edge or Chrome. Keep game.js, style.css and the photos folder beside it. No installation or internet is needed for play. F11 enters full screen in most desktop browsers.

PLAY
Enter a nickname. Answer four photo questions and one AI-prediction question. Each question allows 10 seconds; a timeout earns zero. Answers lock immediately. The showdown advances automatically, then the leaderboard appears. Next Player restarts immediately; otherwise the result screen resets after 25 seconds.

100 points per correct answer, maximum 500. Total answering time breaks ties. Reveal and transition time do not count. Keys 1–4 also select answers.

RECORDED AI MODE
Host Settings > Download AI template exports the image paths, exact questions and answer options. Test the exact images with the selected vision model without supplying the correct labels or answer key. Record the answer text (not an option number), model, test date and original response. Import the completed JSON file through Host Settings. All 13 entries are required. Use AI-testing.html for guided manual testing and result entry. Imported answers are accepted as host-supplied records, not independently authenticated by this application.
Before the convention, expand the image pool, test real model answers, and calibrate human difficulty. Simulated outcomes must not be described as genuine AI performance. The current bank contains 13 photos. Selection draws from provisional difficulty tiers.

LEADERBOARD
Nicknames only. Scores stay in this browser on this laptop; use the same browser and file location for the event. Practice and recorded modes have separate rankings. Host Settings can export all scores or clear them with confirmation. Export before clearing browser data or moving the game. Private browsing may not retain scores. Host controls are intentionally not password protected.
